# NeuroToolbox

This is a Python toolbox for the surface-based analysis of topographic numerosity maps on the cortical surface.

The toolbox accompanies the MSc thesis:

**Automated Geometric Analysis of Topographic Numerosity Maps in the Human Parietal Cortex**

## Features

- Coordinate transformation from mrVista to FreeSurfer
- Surface projection of model parameters
- Automated candidate cluster detection
- Interactive cluster refinement
- Topographic direction analysis
- Anatomical ridge and fundus extraction
- Cross-subject correspondence analysis

Documentation and example workflows will be expanded over time.
